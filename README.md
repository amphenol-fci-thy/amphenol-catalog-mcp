# Amphenol Catalog MCP

Shared agent configuration, search skills, reference material, and MCP integration for verified Amphenol product catalog discovery.

## Repository contents

- `.claude/`, `.codex/`, and `.devin/`: shared agent and MCP configuration
- `amphenol-search/`: product-search skill and its verification references
- `AGENTS.md` and `CLAUDE.md`: repository instructions for AI agents

## Contribution and releases

The `prod` branch contains approved production-ready changes. Create a short-lived branch for each change and open a pull request into `prod`. Production releases are tagged using semantic versions such as `v0.1.0`.
